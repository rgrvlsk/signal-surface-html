# Changelog

All notable changes to Signal Surface HTML are documented here.

## 0.1.0 - 2026-05-19

- Initial public release of the Signal Surface HTML Codex plugin.
- Added the `$s2-html` router skill and ten specialized surface skills.
- Added the shared `surface-kit` compiler and self-contained HTML runtime.
- Added fixture rendering, runtime size checks, package dry-run support, and CI.
